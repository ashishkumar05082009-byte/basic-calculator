# Basic Calculator - School Project

A simple command-line calculator built in Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division (with zero-division protection)
- Interactive menu-driven interface

## How to Run

```bash
python calculator.py
```

## Usage

1. Choose an operation (1-4)
2. Enter two numbers
3. View the result
4. Or select 5 to exit
